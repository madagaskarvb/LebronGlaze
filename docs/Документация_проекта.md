## 1. Обзор проекта

### 1.1 Описание
Данный проект представляет собой комплексный фан-сайт, посвященный ЛеБрону Джеймсу - одному из величайших баскетболистов всех времен. Сайт демонстрирует его выдающуюся карьеру в НБА, бизнес-проекты, благотворительную деятельность и предоставляет контактную информацию для фанатов и заинтересованных лиц.

Проект разработан с использованием чистого HTML и CSS (без JavaScript), что демонстрирует современные принципы веб-дизайна при сохранении простоты и доступности.

### 1.2 Цели web-сайта
✓ Предоставить фанатам и любителям баскетбола полную информацию о карьере ЛеБрона Джеймса, его достижениях в НБА и вкладе в развитие баскетбола.

✓ Осветить внекортовую деятельность ЛеБрона Джеймса: бизнес-проекты, развлекательные инициативы, образовательные программы и благотворительную деятельность.

✓ Создать визуально привлекательный и информативный ресурс, который будет служить образовательным материалом для студентов, изучающих влияние спортивных деятелей на общество.

✓ Продемонстрировать возможности современной веб-разработки с использованием только HTML и CSS (без JavaScript), показав, что можно создать интерактивный и красивый сайт с минимальным набором технологий.

✓ Обеспечить поддержку имиджа ЛеБрона Джеймса как выдающегося спортсмена, предпринимателя и филантропа.

✓ Предоставить централизованный источник официальных ссылок на проекты и инициативы ЛеБрона Джеймса.

### 1.3 Задачи web-сайта
✓ Предоставить подробную хронологию карьеры ЛеБрона Джеймса в НБА с 2003 года по настоящее время, включая все команды, достижения и статистику.

✓ Предоставить информацию о бизнес-проектах ЛеБрона: SpringHill Entertainment, Blaze Pizza, партнерство с Nike, инвестиционная деятельность.

✓ Предоставить информацию о развлекательных проектах: фильмы, телевизионные шоу, продюсерская работа.

✓ Предоставить информацию об образовательных инициативах: школа I Promise, стипендиальные программы, поддержка образования.

✓ Предоставить информацию о благотворительной деятельности: Фонд семьи ЛеБрона Джеймса, общественные программы, социальная справедливость.

✓ Предоставить контактную информацию и официальные ссылки на все проекты и платформы ЛеБрона Джеймса.

✓ Обеспечить круглосуточный доступ к информации через адаптивный дизайн, работающий на всех устройствах (десктоп, планшет, мобильный).

✓ Создать интуитивно понятную навигацию для быстрого доступа к нужной информации.

✓ Реализовать визуально привлекательный дизайн с использованием аутентичных цветов и шрифтов команд НБА.

✓ Обеспечить высокую производительность сайта и быструю загрузку страниц.

### 1.4 Целевая аудитория
- Фанаты ЛеБрона Джеймса и любители баскетбола
- Студенты, изучающие спортивных деятелей и их влияние
- Люди, интересующиеся предпринимательством спортсменов и благотворительностью
- Студенты веб-разработки, изучающие реализацию HTML/CSS

## 4. CSS-архитектура и стилизация

### 4.1 Глобальные стили

#### Сброс стилей
```css
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
```

#### Цветовая схема
| Элемент | Цвет | Hex-код |

#### Типографика

- **Пользовательские шрифты:** NBA Cavaliers, Lakers, Heat

  - h1: 3.5rem (десктоп), 2.5rem (мобильный)

### 4.2 Техники раскладки

| Техника | Применение | Пример кода |
|---------|------------|-------------|
| **Flexbox** | Навигация, секции карьеры, вводный контент | `display: flex; align-items: center;` |
| **CSS Grid** | Сетка проектов, сетка статистики | `display: grid; grid-template-columns: repeat(3, 1fr);` |
| **Позиционирование** | Фиксированная навигация, абсолютные оверлеи | `position: sticky; top: 0;` |
| **Трансформации** | Эффекты при наведении, увеличение изображений | `transform: translateY(-5px) scale(1.05);` |

### 4.3 Продвинутые CSS-возможности

#### Градиенты
```css
/* Линейные градиенты для фонов */
background: linear-gradient(135deg, #fdb927 0%, #552583 100%);

/* Текстовые градиенты */
background: linear-gradient(135deg, #ffffff 0%, #cccccc 100%);
-webkit-background-clip: text;
-webkit-text-fill-color: transparent;
```

#### Переходы
```css
/* Плавные изменения свойств */
transition: all 0.3s ease;

/* Специфичные переходы для производительности */
transition: transform 0.5s ease, filter 0.3s ease;
```

#### Псевдоэлементы
```css
/* Анимированные подчеркивания заголовков */
.career-text h2::after {
    content: '';
    position: absolute;

    left: 0;
    width: 80px;
    height: 4px;
    background: currentColor;
    transition: width 0.3s ease;
}

.career-card:hover .career-text h2::after {
    width: 150px;
}
```

#### Специальные свойства
```css
/* Размытие фона */
backdrop-filter: blur(10px);

/* Тени текста для глубины */
text-shadow: 0 0 20px rgba(255, 255, 255, 0.5);

/* Тени блоков для эффекта возвышения */
box-shadow: 0 8px 30px rgba(0, 0, 0, 0.4);
```

## 5. Адаптивный дизайн

### 5.1 Точки останова (Breakpoints)
Сайт использует подход mobile-first с одной основной точкой останова:

- **Десктоп:** Стили по умолчанию (> 768px)
- **Мобильный/Планшет:** Media query при max-width: 768px

### 5.2 Мобильные адаптации

| Элемент | Десктоп | Мобильный |
|---------|---------|-----------|
| **Навигация** | Горизонтальная flex-раскладка | Вертикальная стопка |
| **Сетка проектов** | 2 колонки | 1 колонка |
| **Сетка статистики** | 3 колонки | 2 колонки |
| **Секции карьеры** | Бок о бок (текст + изображение) | Стопка (текст над изображением) |
| **Размеры шрифтов** | Крупнее (h1: 3.5rem) | Мельче (h1: 2.5rem) |
| **Отступы** | Щедрые (3rem) | Компактные (1.5rem) |
| **Высота изображений** | 100vh (полный экран) | 50vh (половина экрана) |

### 5.3 Дизайн для сенсорных устройств
- Увеличенные области нажатия (минимум 44x44px)
- Достаточное расстояние между интерактивными элементами
- Эффекты при наведении также работают на сенсорных устройствах
- Отсутствие функциональности, зависящей только от наведения

## 6. Навигация и пользовательский опыт

### 6.1 Структура навигации
```
Главная навигация (header)
├── Проекты (index.html) - активна по умолчанию
├── Карьера (career.html)
└── Контакты (contacts.html)
```

**Особенности:**
- Фиксированная позиция при прокрутке (`position: sticky`)
- Активное состояние для текущей страницы (класс `.active`)
- Эффекты при наведении (изменение фона)
- Адаптивная раскладка (горизонтальная → вертикальная на мобильных)

### 6.2 Интерактивные элементы

#### Карточки проектов
- **Состояние покоя:** Базовый стиль с легкой тенью
- **При наведении:**
  - Подъем на 5px вверх
  - Усиление тени
  - Изменение цвета границы
  - Плавный переход 0.3s

#### Секции карьеры
- **Состояние покоя:** Полноэкранные секции с командными цветами
- **При наведении:**
  - Подъем карточки
  - Увеличение изображения (zoom)
  - Расширение подчеркивания заголовка
  - Изменение цвета границы
  - Увеличение яркости изображения

#### Форма контактов
- **Поля ввода:**
  - Базовый стиль с темным фоном
  - Фокус: фиолетовая граница
  - Плавные переходы
- **Кнопка отправки:**
  - Базовый серый цвет
  - При наведении: фиолетовый градиент + подъем
  - При нажатии: возврат в исходное положение

### 6.3 Визуальная иерархия
1. **Уровень 1:** Крупные заголовки с градиентами (имя ЛеБрона)
2. **Уровень 2:** Заголовки секций с командными цветами
3. **Уровень 3:** Подзаголовки и описания
4. **Уровень 4:** Вспомогательный текст и метки

## 8. Доступность (Accessibility)

### 8.1 Семантический HTML
- Использование правильных HTML5-элементов
